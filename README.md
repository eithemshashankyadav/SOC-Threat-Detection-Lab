# SOC Threat Detection Lab

A hands-on Security Operations Center (SOC) lab focused on security monitoring, threat detection, log analysis, alert investigation, and incident response.

## Overview

This project demonstrates a SOC environment for collecting, monitoring, analyzing, and investigating security events from endpoints and network security tools.

## Security Technologies

- Wazuh SIEM/XDR
- Windows Event Logs
- Sysmon
- Suricata IDS/IPS
- pfSense Firewall
- File Integrity Monitoring (FIM)
- VirusTotal Threat Intelligence
- MITRE ATT&CK

## SOC Workflow

1. Collect security events from endpoints and network sources.
2. Centralize and monitor security logs.
3. Detect suspicious activity and security events.
4. Analyze and investigate alerts.
5. Map relevant activity to MITRE ATT&CK.
6. Document findings and recommended defensive actions.

## Key Detection Scenarios

- SSH brute-force attempts
- Suspicious authentication activity
- Network-based threats
- File integrity changes
- Endpoint security events
